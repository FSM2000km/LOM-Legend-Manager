# 活俠傳 伝説管理ビューワ

ローカルHTTPサーバーを使わないPySide6デスクトップアプリです。伝説TXTとMOD受信箱を読み込み、一覧、全文検索、タグ、メモ、重複、手動補正をSQLiteで管理します。

## 起動

通常は`Start-LegendViewer.cmd`をダブルクリックします。`LegendViewer.exe`があればEXEを優先し、なければ`.venv`のPythonを使います。

配布版の`LegendViewer.exe`には日本語プリセットとQtWebEngineが内蔵されています。EXEはデスクトップなど任意のフォルダへ単独で移動しても動作し、ローカルHTTPサーバーは起動しません。

VS Codeではワークスペース直下を開き、実行構成`Legend Viewer`を選択します。テストはタスク`Legend Viewer: Test`から実行できます。

## 初回セットアップ

配布EXEを使わない場合だけ、PowerShellで次を実行します。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Setup-LegendViewer.ps1
```

PySide6は`LegendViewer\.venv`だけに導入され、システムPythonは変更しません。

## 保存場所

```text
伝説TXT:
%USERPROFILE%\AppData\LocalLow\Obb Studio\Mortal\Legend

SQLite:
%USERPROFILE%\AppData\LocalLow\Obb Studio\Mortal\LegendManager\legend_manager.db

MODイベント:
%USERPROFILE%\AppData\LocalLow\Obb Studio\Mortal\LegendManager\inbox
```

DBのバックアップはアプリ上部の`DBをバックアップ`から作成できます。

## 操作

- `再読込`: MOD受信箱を取り込み、伝説フォルダを再走査します。起動中は3秒間隔で変更も監視します。
- `確定情報を保存`: ED名と結縁相手を手動確定します。`唐嬌嬌`も選択できます。手動値は後の自動走査で上書きしません。
- `ED名と結縁相手でリネーム`: 確定情報から安全なファイル名を作ります。衝突時は`_2`以降を付け、既存ファイルを削除しません。
- `タグ`: 生存、唐門加入、金烏上人死亡は通常候補に表示します。観測済みであっても別ルートを示唆し得る候補は`ネタバレタグを追加`を押すまで表示しません。
- `本文検索`: `Ctrl+F`で現在の本文を検索し、`Enter`または`Shift+Enter`で前後へ移動します。標準のルビ表示では読みも検索できますが、読みを無視する設定では表示されない読みは検索対象外です。
- 本文上部には、ED名・結縁相手を除く確定済みタグを横一列で表示します。右側のタグエディタは従来どおり編集に使用できます。
- `確定情報を文頭に追記`: ED・結縁相手、確定タグ、主人公能力などから大カテゴリを選び、TXTへ直接書きます。同じ管理ブロックを置換するため重複せず、本文ハッシュは変わりません。
- ED、結縁相手、既知タグ、人物傾向を複数選択して絞り込めます。人物傾向は性情・処世・品性・道徳を個別に指定でき、タグは「すべて含む」「いずれかを含む」を切り替えられます。
- 一覧見出しをクリックすると昇順・降順を切り替えられます。人物傾向は性情・処世・品性・道徳の4列に分かれ、数値を出さず段階名だけを表示します。
- 一覧の各列は見出しの境界をドラッグして幅を変更できます。変更した列幅は `viewer.ini` に保存され、次回起動時に復元されます。狭い幅では横スクロールを使用できます。
- 伝説ごとの本文スクロール位置と、最後に選択していた伝説を復元します。本文が変わった場合は先頭から表示します。
- `MOD設定`からLOM Legend ManagerのCFGを編集できます。ゲーム終了中だけ保存でき、変更は次回ゲーム起動時から反映されます。
- `本文表示設定`: 本文のフォント、8～48pxの文字サイズ、ルビ表示・読みの無視・カーソル表示を変更します。
- `ED画像表示`: MODが同じED名に対して回収した画像を表示します。ゲーム内の伝説一覧で一度開いたEDは、本の背景を含む表示画像へ更新されます。未回収時は空白です。
- `パス設定`: ゲーム本体の場所を指定し、必要なら伝説TXT・ED画像の保存先を上書きします。
- `一覧`、`詳細`: 左右のサイドバーを個別に隠し、同じボタンで再表示します。

0.2.0以降に保存された伝説では、右側の`保存時パラメータ`から主人公能力、性情・処世・品性・道徳、所持金、名声、団結、遭遇済み人物の好感度、取得済みスキルとレベルを折りたたんで確認できます。性情などはゲーム内の段階名と数値を併記します。

外部アプリで本文が変更された後は、誤上書きを防ぐため確定情報の追記を拒否します。`再読込`して内容を確認してから再実行してください。

## 既存ファイル

既存TXTは初回にDBへ登録し、自動リネームしません。MOD起動時に保存済み伝説スロットから再生成した本文とSHA-256が完全一致した場合だけEDを確定します。結縁相手は成立済みStory keyと完全一致した場合だけ自動確定し、該当しなければ`結縁相手不明`として扱います。Story keyを持たない旧ファイルでは、ファイル名に明記された相手を低優先度情報として維持します。

## コマンド

```powershell
# UIを開かず同期
.\.venv\Scripts\python.exe -m legend_viewer --sync-only

# テスト
$env:QT_QPA_PLATFORM='offscreen'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

初期版はEDだけを対象にします。死亡記録の独自エクスポートは将来拡張です。
