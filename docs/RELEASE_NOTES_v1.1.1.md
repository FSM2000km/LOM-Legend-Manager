# LOM Legend Manager v1.1.1 リリースノート

## 変更点

### Viewer

- 伝説一覧の行にカーソルを合わせると、タグとメモを確認できるようにしました。
- 一覧のタグ列を削除し、一覧の幅を見やすく整理しました。
- ED・結縁相手の下に人物傾向・タグの絞り込みを配置しました。
- 「解除」を「お気に入りのみ」「非表示も表示」と同じ行へ移動しました。
- 非表示の伝説を表示した場合、行をグレー表示し、先頭に`✕`を表示します。
- お気に入りは従来どおり先頭に`★`を表示します。

### MOD設定

- 既存TXTと保存済み伝説スロットの突合は標準で無効になりました。
- 必要な場合だけ`MatchExistingFiles=true`にすると、1回だけ突合を実行し、正常完了後に自動で無効へ戻ります。

## 導入

1. ゲームとLegend Viewerを終了します。
2. 配布ZIPの`BepInEx`フォルダをゲームフォルダへ上書き展開します。
3. 配布ZIPの`LegendViewer`フォルダを任意の場所へ配置します。
4. `LegendViewer.exe`または`Start-LegendViewer.cmd`を起動します。
