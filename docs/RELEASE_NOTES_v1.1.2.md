# LOM Legend Manager v1.1.2

## 修正

- `Title_partner`（タイトル画面に表示される相手）を結縁判定の根拠から除外しました。
- 結縁相手は、ゲーム内の確定済みStoryキーを優先して判定します。
- Storyキーが存在しない、または複数の相手が同時に確定する場合は、推測せず未確定として扱います。
- 判定結果の更新時に、古い結縁タグと自動生成ファイル名を安全に整理します。
- これにより、龍湘と結縁したED32「志に殉ず」を小師妹として扱う問題を修正しました。

## 互換性

- DB内部バージョンは2のままで、既存DBの構造変更はありません。
