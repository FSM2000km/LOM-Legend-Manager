# LOM Legend Manager v1.2.0

現行ゲームのED一覧に対応し、小梅・小竹の結縁判定を追加しました。

## 更新内容

- EDカタログを54件から66件に更新し、ED55〜66をMOD・Viewerの両方へ追加しました。既存EDの表示名6件も現在の日本語化データに合わせました。
- 同名の「崆峒掌派人」はED60・61・65をIDまたはED番号で区別します。名前だけでは一つに決めません。
- 小梅の結婚後の唐門帰還と、小竹の別分岐での婚礼・結婚後の生活・臨終の婚礼・妻としての唐門帰還を、記録済みStoryキーで判定します。
- 婚約や作り話の婚姻は結縁として扱いません。根拠がない場合や、異なる相手の確定記録が併存する場合は未確定とします。追加EDの名前から相手は推定しません。
- ViewerのWindows向けビルドで、ビルド環境上の同名ICU DLLが混入して起動を妨げる問題を修正しました。

## 既存データと互換性

- お気に入り、一覧からの削除と再表示、一覧列、絞り込み、本文・詳細表示などの既存機能を維持しています。
- DB内部バージョンは2のままです。手動設定したメタデータを維持し、記録済みのStoryキーがある伝説は再読込時に新しい判定で照合します。
- タイトル画面に表示される相手は、従来どおり結縁判定に使いません。
- 配布版はv1.2.0、Viewer内部バージョンも1.2.0です。MOD DLL内部バージョンは従来の1.0.0のままです。

## 確認した環境と範囲

- Steam build 26021712、日本語化データ2026.10.16.376でEDのID・66件の件数・並び順・表示名を照合しました。
- MODのビルドとゲームAPI参照、結縁判定のMOD・Viewer間の整合、Viewerの回帰テストと配布EXEによる隔離データの取り込みを確認しました。
- 各追加EDをゲーム内で新たに到達して出力する操作は確認していません。

結縁判定の追加根拠はソース内の`docs/RELATIONSHIP_RULES_2026-10-19.md`に記録しています。
