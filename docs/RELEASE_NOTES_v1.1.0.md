# LOM Legend Manager v1.1.0 リリースノート

## 概要

伝説Viewerの一覧管理を拡張しました。お気に入りと非表示を伝説ごとの状態として保存でき、再起動や再同期後も同じ状態で利用できます。

## 変更点

### Viewer

- 一覧の先頭にお気に入り列（`★`）を追加しました。
- お気に入りの伝説は一覧の背景色で識別できます。
- 一覧の右クリックメニューから、お気に入りの追加・解除と一覧から削除・復元ができます。
- 詳細情報の「一覧管理」からも、お気に入りの追加・解除ができます。
- 「お気に入りのみ」フィルターを追加しました。
- 「一覧から削除」はTXTを削除せず、Viewerの通常一覧から一時的に非表示にします。
- 「非表示も表示」を有効にすると非表示の伝説を確認でき、「一覧に戻す」で復元できます。
- 非表示の伝説には一覧の状態列に「非表示」と表示します。

## データについて

- 「一覧から削除」では伝説TXT、本文、DBレコードを物理削除しません。
- お気に入り・非表示の状態は再起動や再同期後も保持されます。

## 導入

1. ゲームとLegend Viewerを終了します。
2. 配布ZIPの`BepInEx`フォルダをゲームフォルダへ上書き展開します。
3. 配布ZIPの`LegendViewer`フォルダを任意の場所へ配置します。
4. `LegendViewer.exe`または`Start-LegendViewer.cmd`を起動します。
